# Quiet Register

Quiet Register borrows its order from a building plan. A steady margin and a few fine rules mark thresholds between tasks. The grid gives each view its own address, while shared axes make the whole spread feel like one place.

Deep ink and soft mint carry the warmth of the interface into the surrounding page. The darker access board gives the QR code, door key and activity record enough contrast to stand apart. Colour identifies the part of the experience on display, without competing with it.

Window frames and phone silhouettes set the scale. Each overview gives one or two screens room to establish context, then moves closer for the steps that matter. The crops preserve the interface and leave enough space for the eye to find the next action.

A serif headline names the experience in ordinary language. Small sans-serif captions mark roles and tasks, while the screen itself supplies the evidence. Repeated labels and finishes make the boards feel like a set even when the arrangements change.
